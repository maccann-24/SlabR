# Step 7: Mobile Security — Not Applicable

ServiceLine AI has no mobile application component. The product is a voice/SMS service with a web-based admin panel and client dashboard. No mobile hardening is required.

If a mobile app is added in the future, apply:
- Certificate pinning for API communication
- Biometric authentication for admin access
- Encrypted local storage (Keychain/Keystore)
- Anti-tampering and root/jailbreak detection
